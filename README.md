# Générateur de phrase personnalisée (Python - Tkinter)

## Description
Ce projet est une petite application en interface graphique qui génère une phrase personnalisée.  
L'utilisateur entre son prénom et le programme affiche "Bonjour <prénom>".

## Objectif
J'ai réalisé ce projet pour m'entraîner à :
- utiliser Tkinter pour créer des interfaces simples
- récupérer des entrées utilisateur
- mettre à jour dynamiquement du texte dans l’interface

## Fonctionnalités
- Saisie du prénom par l'utilisateur
- Génération et affichage d'une phrase personnalisée
- Interface simple avec un champ texte, un bouton et un label

## Fonctionnement
1. L'utilisateur entre son prénom
2. Il clique sur le bouton "Faire la phrase."
3. Le programme affiche "Bonjour <prénom>"

## Technologies utilisées
- Python
- Tkinter

## Lancer le projet
1. Installer Python
2. Exécuter le fichier :
```bash
python phrase.py
